# Code of Conduct

We use the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as the project code of conduct.

Be respectful, assume good intent, discuss evidence rather than people, and never publish another person's device logs, identifiers, credentials or private firmware dumps. Maintainers may remove abusive, unsafe or privacy-invasive contributions.

Report conduct concerns privately using the contact method in `SECURITY.md`.
